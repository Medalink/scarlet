Scarlet API map

Every function and event the WoW Forever client documents, sorted by what it is about. A data point is an event or a function that reads state; actions like Set, Open and Craft are listed but not counted. Live means a file the Forever client loads calls it, so the API works in Forever and not only in retail. Coverage counts live data points, minus the ones a review judged not worth recording; each of those shows its reason.
