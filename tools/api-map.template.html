Scarlet API map

Every function and event the WoW Forever client documents, sorted by what it is about. A data point is an event, a function that reads state, or a function the docs say returns something; actions that return nothing are listed but not counted. Every data point in a game domain is either recorded by Scarlet or left out with a written reason, so none stays undecided. "Undocumented" holds the globals the Forever client's interface code calls that the docs do not list. The Live badge says a file the Forever client loads calls the API; it is a fact about the client and does not change what needs a decision. "Interface and other" is listed and not counted.
